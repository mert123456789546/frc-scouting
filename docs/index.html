FRC Scouting

Takım numarasını gir, maç geçmişi, istatistikler ve yapay zeka analizi karşına gelsin.

Windows

Kurulum dosyasını indir (.exe)
  1. İndirilen FRC_Scouting_Setup.exe dosyasını çalıştır.
  2. Windows "bilgisayarınızı korudu" uyarısı çıkarsa Ek bilgi → Yine de çalıştır de (uygulama henüz dijital imzalı değil).
  3. Kurulum sihirbazındaki adımları izle, bitince uygulama açılır.

Android

APK'yı indir (.apk)
  1. Dosyayı indir ve aç.
  2. "Bilinmeyen kaynaklardan yüklemeye izin ver" sorulursa izin ver.
  3. Yükle'ye bas. Uygulama listende görünür.

iPhone / iPad

Uygulamayı aç
  1. Bu sayfayı Safari'de aç (Chrome'da çalışmaz).
  2. Paylaş simgesine bas → Ana Ekrana Ekle.
  3. Ana ekrandaki simgeden uygulama gibi açılır.
Veriler The Blue Alliance'tan alınır. Uygulama internet bağlantısı gerektirir.
